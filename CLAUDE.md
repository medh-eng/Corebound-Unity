# Corebound (Unity port)

Unity 6 (6000.3) URP port of Corebound. The web game (github.com/medh-eng/Corebound, frozen at M4 slice 3)
is the **specification**; the plan is `docs/UNITY-PLAN.md` in that repo. Pon is the Commander (final
authority, non-technical); Claude is the Director. No violence: Guardians are calmed, never defeated.
Plain-English commit messages. Never merge design changes without the Commander's yes.

## Layout
- `Assets/Data/Json/<module>/<NAME>.json`: generated by `node scripts/export-unity-data.mjs` in the web repo. Do not hand-edit; re-export.
- `Assets/Scripts/Core` and `Systems`: plain C# with no UnityEngine, so rules can be tested with NUnit.
- `Assets/Scripts/Render`, `UI`, `Audio`: Unity-facing code.
- `Assets/Tests`: NUnit tests ported from the web repo's `tests/`.
- Large binaries are in Git LFS (see `.gitattributes`).

## Porting order (UNITY-PLAN.md)
Step 2 foundations (done) → 3 rules in plain C# + tests → 4 round planet + digging → 5 world/factory/story → 6 visuals → 7 slices 4-6 + builds.
